# New 路径第二套十题定向测试试卷

本试卷用于首套十题定向放行后的交叉场景复验。所有题干和契约均原样选自正式 300 题题库，只运行 `new` 变体，不执行 `old`，也不能替代后续 300 题全量考试。

第二套与 `_other/考试/测试试卷/` 的 10 个题号完全不重叠，覆盖不同菜谱实体、自然表达、步骤锚点、图关系、零路径安全、时间约束语义、软偏好和未收录实体。

## 目录说明

| 文件 | 用途 |
| --- | --- |
| `试卷题库.json` | 10 题的唯一机器可读题源；题干和契约原样来自正式 300 题题库。 |
| `试卷目录.md` | 人工可读的题目、覆盖方向和本轮重点。 |
| `监考提示词.md` | 交给独立监考 AI 的执行说明，只运行 `new`。 |
| `逐题结果.schema.json` | 逐题 JSONL 的格式约束。 |
| `结果/` | 每次运行的预检、冻结 gold、原始响应、审计副本和结论。 |

## 放行条件

本轮只有全部条件满足，才能作为进入下一次 300 题 `new` 全量考试的补充证据：

- `new.jsonl` 恰有 10 条、题号无重复、没有 `blocked` 或 `error`。
- 每道排名题有冻结 gold、可复核候选顺序、PDS 回补和最终证据。
- S01/S02/S03 的审计没有 `ProgrammingError`、`SQLite objects created in a thread` 或 `parent-store-unavailable`。
- S04/S05 的关系结论来自目标图查询；S05-C-04 必须为 `graph_not_found` 并明确“无法证明”。
- S06/S07 有受限候选和 PDS 回补；S07 不作严格营养断言；S08 明确拒答且不编造菜谱。
- 所有禁止断言、无依据关系断言和严格营养误报计数均为 0。

即使本套 10 题全部通过，也仍须以新的运行编号完成 300 题 `new` 全量考试。
