## 3. 顺序运行 10 道线上题

按 `试卷题库.json` 中顺序，对每题调用 `POST /api/chat/stream`：

```json
{
  "message": "<题库原样题干>",
  "session_id": "<运行编号>:new:<题号>",
  "allow_generalized_advice": false
}
```

每题请求前后比对 `run/exam-audits/<运行编号>/` 的一级目录，必须恰好生成一个新审计目录并立即复制。缺少审计、HTTP/SSE 出错、审计无法复核候选或证据时，标记 `blocked`/`error`，不能伪造通过。

逐题审查门槛：

- S01-A-02、S01-B-01：审计必须有实体直达与 PDS 正文证据；禁止出现 `ProgrammingError`、`SQLite objects created in a thread`、`parent-store-unavailable`，也不得进行全文向量检索或使用未回补 chunk。
- S02-A-02：实际路线必须为菜谱步骤锚定，正文证据可复核；禁止任意 Cypher 或全文向量检索。
- S03-A-02：实际路线必须为技巧文档章节解析，正文证据可复核；不得进行全文向量检索或使用未回补 chunk。
- S04-A-02：实际路线为猪肉到菜谱的目标图查询；关系结论必须有验证图事实，最终候选顺序和 PDS 正文证据均可复核。
- S05-A-02：实际路线为猪肉到蔬菜的目标图查询；关系结论必须有验证多跳图事实与 PDS 回补。
- S05-C-04：实际路线必须为 `graph_not_found`，回答明确“无法证明/没有路径”，不得给出搭配关系；`forbidden_assertion_count=0`、`unsupported_relation_claim_count=0`。
- S06-A-02：实际路线必须含 `restricted_vector` 或可复核的受限候选路线；有排序候选、分级 gold 和 PDS 回补，不能使用未回补 chunk。
- S07-A-02：实际路线必须含 `restricted_vector`；回答可使用“少油感觉”等软偏好表述，但不得作未经治理的低脂、低盐、低热量等严格营养断言。否定严格营养断言（例如“并非已验证的低脂选择”）不计为误报。
- S08-A-02：明确未收录或无法在知识库找到该菜，不猜测、不生成做法、食材或步骤。

对于每一行保留：实际 `route`、排名候选、冻结 `gold_items`、实体解析、QueryPlan、图路径、向量范围、PDS 回补、最终证据、检查结果、TTFT/总耗时和完整回答。
