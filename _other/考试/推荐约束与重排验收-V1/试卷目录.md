# 试卷目录

本卷按风险而不是按功能页面组织。RCR-01 至 RCR-11 验证硬约束与冲突处理；RCR-12 至 RCR-16 验证软偏好、数据未知和两段式证据；RCR-17 至 RCR-18 验证兼容与故障收敛。

| 范围 | 题号 | 重点 |
| --- | --- | --- |
| 工具 | RCR-01 至 RCR-03 | 强制、排除、普通偏好的分界。 |
| 做法 | RCR-04 至 RCR-07 | 蒸、炸、炒及 `STIR_FRY` 映射。 |
| 组合条件 | RCR-08 至 RCR-11 | 交集、时长、冲突和无结果。 |
| 软偏好 | RCR-12 至 RCR-15 | 未知字段、份量、少步骤、清爽。 |
| 检索证据 | RCR-16 | Top30 候选与 Top5 正文的分离。 |
| 运行安全 | RCR-17 至 RCR-18 | 开关兼容与单请求故障收敛。 |

每题都应保存 `ConstraintSpec`、硬范围计数、Top30、最终 Top5、分数解释、PDS build ID、manifest SHA-256 和审计引用。题目允许“没有已验证完全匹配项”；这种结果不能被当作失败，前提是系统没有放宽硬约束。
