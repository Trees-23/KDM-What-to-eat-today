# 推荐约束与重排验收卷 V1

本目录是“推荐约束需求单、硬过滤与重排”功能的独立验收包。它不修改、不替代，也不要求运行仓库既有 300 题总题库。

本卷共 18 题，关注新能力最容易出错的边界：用户明确限制是否被严格遵守、普通偏好是否被错误收紧、Top30 到 Top5 是否保留证据链，以及故障时是否诚实收敛。

| 文件 | 用途 |
| --- | --- |
| `试卷题库.json` | 唯一机器可读题源和每题断言。 |
| `试卷目录.md` | 人工可读的覆盖说明。 |
| `评分与验收标准.md` | 硬约束、软偏好和性能的独立判分规则。 |
| `监考提示词.md` | 交给独立监考者的执行指令。 |
| `结果/` | 每次验收的冻结输入、逐题结果、审计引用和结论。 |

运行前必须冻结活动 PDS build、联合 artifact manifest、配置快照和题库 SHA-256。题目不要求指定某一道菜必须出现；当知识库没有完全匹配项时，诚实返回无结果也可以通过对应的硬约束题。
