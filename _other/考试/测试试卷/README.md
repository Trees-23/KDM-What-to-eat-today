# New 路径十题定向测试试卷

本试卷用于全量 `new` 变体考试前的定向放行。它从 `2026-08-12-真实考试-001` 中抽取 10 道曾经 `blocked` 或安全失败的题，不执行 `old` 变体，也不能替代后续 300 题全量考试。

## 目录说明

| 文件 | 用途 |
| --- | --- |
| `试卷题库.json` | 10 题的唯一机器可读题源；题干和契约原样来自正式 300 题题库。 |
| `试卷目录.md` | 人工可读的题目、覆盖方向和上轮失败原因。 |
| `监考提示词.md` | 交给独立监考 AI 的执行说明，只运行 `new`。 |
| `逐题结果.schema.json` | 逐题 JSONL 的格式约束。 |
| `结果/` | 每次运行的预检、冻结 gold、原始响应、审计副本和结论。 |

## 放行条件

本轮只在以下条件全部满足时才允许进入下一次 300 题全量考试：

- `new.jsonl` 恰有 10 条、题号无重复、没有 `blocked` 或 `error`。
- 所有排名题均有冻结 gold、可复核候选顺序、PDS 回补和最终证据。
- S01/S02/S03 的审计中 `entity_direct_pds` 为 `verified`，不出现 `ProgrammingError`、`SQLite objects created in a thread` 或 `parent-store-unavailable`。
- S04/S05 的关系结论来自目标图查询，S05-C-03 保持 `graph_not_found` 且明确说明无法证明。
- S06/S07 有受限向量候选与 PDS 回补；S08 明确拒答且不编造菜谱。
- 所有禁止断言、无依据关系断言和严格营养误报计数均为 0。

即使这 10 题全部通过，也只说明已通过定向放行，仍须以新的运行编号完成 300 题 `new` 全量考试。
