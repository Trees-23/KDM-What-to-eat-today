“如何决策吃什么”是一套用于**确定一餐菜品数量与荤素搭配**的通用决策方法，适合在做饭前、需要为多人安排菜品时使用。

## 关键要点

1. **先按人数确定总菜数**
   - 总菜数 = 人数 + 1。

2. **确定荤菜、素菜的数量**
   - 荤菜数应与素菜数相同，或比素菜多 1 道。
   - 设人数为 `N`、素菜数为 `a`、荤菜数为 `b`：
     - `a + b = N + 1`
     - `a ≤ b ≤ a + 1`
   - 对应计算为：
     - 素菜数：`floor((N + 1) / 2)`
     - 荤菜数：`ceil((N + 1) / 2)`

   - 人数超过 8 人时，可考虑在荤菜中加入鱼类菜品。
   - 有小孩时，可考虑增加带甜味的菜。
   - 可加入特色菜或拿手菜，提升一餐的辨识度和完成度。

4. **荤菜注意肉类来源多样化**
   - 不宜所有荤菜都采用同一种动物肉。
   - 可参考猪肉、鸡肉、牛肉、羊肉、鸭肉、鱼肉的顺序进行选择。
