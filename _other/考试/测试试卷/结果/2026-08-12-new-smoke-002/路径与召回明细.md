```text
“如何决策吃什么”是一套用于确定家常聚餐菜品数量与荤素搭配的简化方法，适合在做饭前、已知用餐人数时快速规划菜单。

## 关键要点

1. **先按人数确定菜品总数**
   - 菜的数量 = 人数 + 1。

2. **用公式分配荤菜与素菜**
   - 设人数为 `N`，素菜数为 `a`，荤菜数为 `b`：
     - `a + b = N + 1`
     - `a ≤ b ≤ a + 1`
   - 即荤菜数量应与素菜相等，或比素菜多一道。
   - 可按以下方式计算：
     - 素菜数：`floor((N + 1) / 2)`
     - 荤菜数：`ceil((N + 1) / 2)`

3. **根据就餐者情况微调**
   - **人数超过 8 人**：可考虑在荤菜中加入鱼类菜品。
   - **有小孩**：可考虑加入带甜味的菜。
   - 可加入特色菜或自己的拿手菜，增强菜单辨识度和完成度。

4. **荤菜注意食材多样性**
   - 不宜所有荤菜都使用同一种动物肉。
   - 可按猪肉、鸡肉、牛肉、羊肉、鸭肉、鱼肉的顺序考虑搭配。
   - 不选择“奇奇怪怪的动物”作为荤菜来源。

- 家庭日常做饭前的菜单规划；
- 多人聚餐、需要快速估算菜量的情形；
- 希望在有限时间内兼顾荤素数量平衡、菜品变化和家庭成员偏好的情形；
```
