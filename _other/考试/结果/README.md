# 结果目录

这里当前只包含结果格式，不包含真实考试结论。

独立监考完成后，在此目录新建一个以日期和运行编号命名的子目录，并写入：

- `preflight.md`：服务、版本、题库 SHA、PDS/Milvus V2 artifact 和实体/关系预检。
- `gold_manifest.json`：首次请求前冻结的实体、关系路径和分级相关性标签。
- `old.jsonl`、`new.jsonl`：逐题原始结果，满足 `逐题结果.schema.json`。
- `responses/`：逐题原始 HTTP/SSE 响应，按 old/new 变体分目录保存。
- `audits/`：从 `run/exam-audits/<运行编号>/` 复制的原始审计目录。
- `考试结果总评.md`：由 `工具/汇总结果.py` 生成的全局指标和分场景指标。
- `路径与召回明细.md`：由汇总器生成的逐题路线、候选、PDS 回补、最终证据和回答。
- `监考结论.md`：监考 AI 基于完整性、指标和逐题证据作出的可签收/不可签收结论。

`逐题结果.example.jsonl` 仅用于格式演示，不能混入真实结果文件。
