# 场景与评分标准

## 试卷结构

每个场景有 A、B、C 三套卷，每套 10 题：

| 卷别 | 含义 | 主要观察点 |
| --- | --- | --- |
| A 正向命中 | 明确、标准的目标问题 | 能否走到正确路线并找回 gold。 |
| B 释义与歧义 | 同意图换说法或相近意图 | 是否理解意图，而不是只匹配关键词。 |
| C 边界与反例 | 证据不足、限制或拒答 | 是否暴露限制，不把猜测包装成事实。 |

## 十个场景

| 场景 | 用户问题类型 | 预期路线 | 主要评分 |
| --- | --- | --- | --- |
| S01 | 菜谱完整做法 | 实体直达 + PDS 全文 | 菜谱命中、完整正文、引用。 |
| S02 | 菜谱第 N 步 | 步骤锚定 + 白名单 QueryPlan + PDS 局部回补 | 目标步骤、邻近正文、无跨步骤串扰。 |
| S03 | 技巧关键要点 | 技巧实体/章节 + PDS | 技巧章节命中、上下文完整性。 |
| S04 | 食材能做什么 | 食材到菜谱的目标图查询 | 图路径正确、菜谱父文档链接。 |
| S05 | 食材搭配蔬菜 | A/B 为食材-菜谱-蔬菜多跳图查询；C 为已解析实体的零路径反例 | A/B 只接受真实图路径；C 必须明确不可证明。 |
| S06 | 语义推荐与本地约束 | ConstraintSpec -> 硬范围 -> Top30 -> 重排 -> Top5 PDS | 强限制不被高向量分绕过，排序相关性和证据分段。 |
| S07 | 川菜软偏好与营养边界 | ConstraintSpec -> 硬范围 -> Top30 -> 重排 -> Top5 PDS | 偏好匹配、局部硬排除和零严格营养误报。 |
| S08 | 未收录菜谱 | 实体未找到 | 拒答准确、零猜测。 |
| S09 | 不可证明关系 | 隔离 TargetedGraphRetriever 合约 | 图 not_found、零正文伪证。 |
| S10 | 图服务不可用 | 隔离故障注入 | 安全降级、零关系幻觉。 |

## 指标口径

成功场景只在 `gold_manifest.json` 已冻结且有分级相关性标签时统计排名指标。

S05 A/B 是排名题，必须在开考前冻结至少一条真实多跳路径。S05 C 是安全题，必须在开考前冻结“实体存在且该多跳路径为零”的查询证据；它的空候选是预期结果，不计 Recall、MRR 或 nDCG。

S06/S07 在冻结分级相关性前，先读取活动 PDS build 的 metadata 并执行题目声明的本地硬范围。若硬范围为空，冻结 `NO_PREFERENCE_RESULTS`，它按安全收敛计分，不再要求至少三个相关 gold，也不计 Recall、MRR 或 nDCG。其余 S06/S07 题必须保留 ConstraintSpec、硬范围计数、Top30 metadata、`recommendation_rerank_v1` 的最终 Top5 审计和最多五篇 PDS 正文证据。

| 指标 | 口径 |
| --- | --- |
| Recall@1/3/5 | 前 K 个候选中找回的相关 gold 数 / 该题全部相关 gold 数。 |
| Precision@1/3/5 | 前 K 个候选中相关项比例，分母固定为 K。 |
| MRR@5 | 第一个相关 gold 的倒数排名；前 5 没有命中为 0。 |
| nDCG@5 | 使用 `2^relevance - 1` 的增益和对数折损，按冻结 gold 的理想排序归一化。 |
| Hit Rate@1/3/5 | 单题前 K 是否至少命中一个相关 gold。 |
| 路由准确率 | 审计中的实际路线是否满足题库契约或记录了受控回退。S06/S07 还必须有本地约束、硬范围和两段式检索审计。 |
| 证据完整率 | 答案中每项关键结论是否有图事实或 PDS 正文支撑。 |
| 证据链接率 | 最终证据是否能指回已冻结的 parent/chunk/sourcePath。 |
| 回答忠实度 | 答案是否只由最终证据支持，限制项是否保留。 |
| TTFT / 总耗时 / P95 | 首 token、单题总耗时及相同分组的 95 分位耗时。 |

安全场景使用下列指标，不计算 Recall、MRR 或 nDCG：

| 指标 | 通过条件 |
| --- | --- |
| 拒答正确率 | S08 明确未找到且不猜测。 |
| 图 not_found 正确率 | S09 返回不可证明，不生成关系路径。 |
| S05 零路径正确率 | S05 C 明确无法由图证明搭配关系，不生成关系路径或文本伪证。 |
| 故障降级正确率 | S10 记录图不可用或受控回退，不称关系已验证。 |
| 禁止断言数 | 所有变体均应为 0。 |
| 无依据关系断言数 | 所有变体均应为 0。 |
| 严格营养误报数 | 所有变体均应为 0。 |

## 结果判读

总评必须分开比较 `old` 和 `new`，不得把二者混在一个分母中。若新路径不可用而走旧路径，只能记为“新路径 blocked/受控回退”，不能计为新路径检索成功。

下列任一情况都使本轮考试不可签收：题目覆盖率不足 100%、重复题目/变体行、gold 在开考后修改、审计文件缺失、候选/路径/证据字段缺失、S06/S07 缺少 Top30/Top5 分段审计、任何安全场景出现禁止断言。
