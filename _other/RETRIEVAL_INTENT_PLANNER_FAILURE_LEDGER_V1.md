# 意图规划验收失败台账

## 回归规则

全量正式题库仅用于建立基线和第 9.5 节最终验收。一次全量运行完成后，运行器输出的
`failure-summary.json` 是唯一允许的后续回归输入：下一轮从当前官方题库按其中的
`question_id` 重新冻结题目。单题失败不会中断同一轮，也不会触发 300 题重跑。

每轮结束后：

1. 保留逐题 JSONL、审计目录、验收报告和失败摘要。
2. 从通过的题目中移除；仅对遗留失败题建立下一轮冻结回归集。
3. 先集中完成同类根因诊断与最小修复，再执行下一轮失败集回归。
4. 只有失败集清零且第 9.5 节其他闸门齐备时，才重新执行 300 题最终验收。

不得手工改写题干、替换题号、伪造图事实或用题号/固定 ID 绕过编译器。
